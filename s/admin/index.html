처음 한 번: GitHub 토큰 연결

  1. GitHub 토큰 만들기 페이지를 엽니다 (hq1trinity-arch 계정으로 로그인).
  2. Token name은 trinity-shortlinks, Expiration은 1년, Repository access는 Only select repositories → trinity-lecture-page.
  3. Permissions → Repository permissions에서 Contents: Read and write만 켜고 Generate token.
  4. 생성된 토큰(github_pat_로 시작)을 아래에 붙여 넣고 저장합니다. 토큰은 이 브라우저에만 저장되며 어디로도 전송되지 않습니다.
trinityone.co.kr/s/

영문 소문자·숫자·하이픈만 사용. 기억하기 쉬운 이름도 됩니다 (예: form-1013, basecamp).
